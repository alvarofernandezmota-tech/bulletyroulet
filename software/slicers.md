# 🖥️ Software — Slicers

## Slicer principal: Chitubox Free ✅

| Campo | Info |
|-------|------|
| **Estado** | ✅ Instalado — 23 mayo 2026 |
| **Precio** | Gratis |
| **Descarga** | https://www.chitubox.com |
| **Compatibilidad** | Windows / Mac / Linux |
| **Formato salida** | `.pwma` (compatible Photon V1) |

### Por qué Chitubox
- ✅ **Soportes automáticos incluidos gratis** — clave para principiantes
- ✅ Perfil preconfigurado para Anycubic Photon V1
- ✅ Interfaz sencilla
- ✅ Comunidad enorme, tutoriales abundantes
- ⚠️ Muestra algunos anuncios en versión gratuita

### Paneles principales
| Panel | Para qué sirve |
|-------|---------------|
| **Machine** | Config impresora: tamaño cama, resolución |
| **Resin** | Perfil resina: tiempos exposición, temperatura |
| **Print** | Grosor capa, velocidad |
| **Advanced** | Ajustes finos avanzados |

### Configuración inicial
1. Abrir Chitubox → **Settings → Printer → Add printer**
2. Buscar **"Anycubic"** → seleccionar **"Photon"** (sin letra)
3. Confirmar → aparece la plataforma de construcción
4. Añadir perfil de resina cuando se conozca la marca

### Flujo de trabajo
```
1. Importar STL
2. Orientar modelo (30-45° para minimizar superficie de succión)
3. Soportes automáticos → revisar manualmente
4. Configurar perfil de resina
5. Slicear → vista previa capa a capa
6. Exportar .pwma → USB → imprimir
```
