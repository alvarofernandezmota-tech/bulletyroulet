| | Chitubox Free | Lychee Free | PrusaSlicer |
|---|---|---|---|
| Soportes automáticos | ✅ Gratis | ❌ Solo premium | ✅ Gratis |

## 📚 Conceptos aprendidos

### Identificar Photon V1 vs modelos posteriores
- **V1 original**: un solo rail central → es la nuestra
- **S y posteriores**: dos barras laterales, carcasa más cuadrada

### Flujo completo
```
1. STL (Thingiverse/Printables)
2. Chitubox → orientar → soportes → slicear → .pwma
3. USB → Photon V1 → imprimir
4. Lavar IPA + curar UV
```

### Qué guardar dónde
- ✅ **STL** → en la repo `modelos/[nombre]/`
- ❌ **.pwma** → en USB/Drive (pesan 50-200MB, no van a Git)

### Paneles Chitubox
| Panel | Para qué |
|-------|----------|
| Machine | Config impresora: tamaño cama, resolución |
| Resin | Perfil resina: tiempos exposición |
| Print | Grosor capa, velocidad |
| Advanced | Ajustes finos avanzados |
