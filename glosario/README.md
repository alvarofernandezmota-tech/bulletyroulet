# 📖 Glosario

Diccionario de términos de impresión 3D con resina.

## Términos

| Término | Definición |
|---------|------------|
| **Layer time** | Segundos de exposición UV por capa normal |
| **Bottom layers** | Primeras capas que fijan la pieza a la placa |
| **Bottom exposure** | Tiempo exposición primeras capas (mucho más alto que las normales) |
| **Lift speed** | Velocidad de subida de la placa entre capas |
| **IPA** | Isopropanol 99% — líquido de lavado post-impresión |
| **Curado** | Exposición UV adicional tras lavar para endurecer la pieza |
| **FEP** | Lámina transparente del fondo de la cubeta (consumible) |
| **Soportes** | Estructuras que sostienen partes voladas durante la impresión |
| **.pwma** | Formato de archivo de Chitubox para Anycubic Photon V1 |
| **Slicer** | Programa que convierte el STL en capas imprimibles |
| **STL** | Formato de archivo 3D estándar |
| **MSLA** | Masked Stereolithography — tecnología de la Photon V1 |
| **Islas** | Capas sin soporte detectadas por UVtools — causan fallos |
